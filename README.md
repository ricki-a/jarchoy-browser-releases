# JarChoy Agent Browser

Browser Android buatan sendiri — ringan, ada VPN-nya, bisa simpen password, temanya kegelavan yg abadi 🤘

## Fiturnya

### Browser
- Tab banyak + preview
- Bookmark (favicon otomatis kesimpen)
- History & download manager
- Mode privat
- Ad-block bawaan (bye-bye iklan!)
- Scanner QR/Barcode/QRIS

### VPN (SSH / VLESS / Trojan)
- **SSH** — paling stabil, udah terbukti jalan
- **SSH over WebSocket** — tembus firewall kantor/sekolah (port 80/443)
- **VLESS & Trojan** — protokol kekinian (TCP/WS/TLS)
- **DNS-over-HTTPS** — biar nggak dibajak DNS-nya sama ISP nakal
- Tinggal paste link `vless://` atau `trojan://`, otomatis kepasang!

### Password Manager
- Otomatis nawarin simpen password
- Autofill sekali tap
- Rapi per domain

### Tema
- **Midnight Metal** — hitam + merah, buat dark mode 
- Mode terang juga ada
- Semua dialog gaya iPhone

## Cara Install

1. Download file `.apk` dari [Releases](../../releases) yang paling baru
2. Di HP, buka **Pengaturan** → **Keamanan** → nyalain **"Sumber tidak dikenal"**
3. Buka file APK-nya → **Install**
4. Jadi! 

> **Catatan:** Belum ada di Play Store ya  Install manual dulu.

## Butuh Apa

- Android 8.0 ke atas
- ~2MB doang!
- Internet
